# Steam 1.0 Scope

The feature scope below is locked. Exact balance and the details of validated rules are not.
Changing the feature lists means reopening the scope decision. Tuning within them does not.

## Principles

1. The free itch version stays a complete, good core game.
2. Steam differentiates through mastery, content and platform depth, not by withholding basic UX quality.
3. Debrief, Grade Breakdown, Same-seed Retry and readability fixes belong to the shared core.
4. The same seed should keep representing the same mountain wherever possible.
5. Feature scope is locked. Exact balance and validated rule details are not.
6. New generic roguelite systems are not added to 1.0 without reopening the scope decision.

## Shared Core (itch + Steam)

- Procedural expeditions
- Deterministic, shareable seeds
- Explorer
- Standard
- Movement stamina 1 / 3 / 8
- Elevation vision, line of sight, panorama
- Supply Camps
- Sight Line readability (480 m / 840 m sight lines on the sheet): kept after playtest
- Failure / Victory Debrief
- Grade Breakdown
- Same-seed Retry
- Basic Records

## Steam Mastery Layer

- Curated Survey Contracts
- Validated Advanced / Expert expedition rules
- Steam Achievements
- Steam Cloud
- Expanded long-term Records and statistics
- Windows standalone build
- Gamepad / Steam Deck support, if verified

## Explicitly deferred from Steam 1.0

- Starting equipment / loadouts
- Inventory
- Random weather
- Altitude sickness
- Meta stat progression
- Combat
- Generic roguelite item systems

## Not balance-locked yet

- Exact Explorer information assists
- Exact Expert rules and combinations
- Number and conditions of Contracts
- Achievement conditions
- Future vision-band refinement, only if later human testing proves it necessary
