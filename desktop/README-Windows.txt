The Carto-Rogue: 등고선 탐사대 — Windows 버전 / Windows build
==============================================================

[한국어]

실행 방법
  1. 받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 "압축 풀기"(모두 압축 풀기)를 선택합니다.
     zip 안에서 바로 실행하지 말고 반드시 압축을 푼 뒤 실행해 주세요.
  2. 압축을 푼 폴더에서 CartoRogue.exe 를 실행합니다.
     설치 과정은 없으며 인터넷 연결 없이 모든 기능을 플레이할 수 있습니다.

  "Windows의 PC 보호" 창이 뜨는 경우
     이 빌드는 코드 서명이 되어 있지 않아 인터넷에서 받은 파일에 대해 SmartScreen 경고가
     표시될 수 있습니다. "추가 정보"를 누른 뒤 "실행"을 누르면 게임이 시작됩니다.

  요구 사항: Windows 10 또는 Windows 11 (64비트)

조작
  방향키 / WASD      이동 (지도 위를 클릭하면 그쪽으로 한 걸음, 누르고 있으면 계속 이동)
  Enter / Space      시작 · 확인
  R                  새 지도
  P / Esc            일시정지 메뉴
  L                  원정 기록실 (타이틀 · 결과 화면)
  H                  결과 카드 숨기기 / 보이기
  M                  음소거
  F                  전체화면 켜기 / 끄기
  화면 오른쪽 아래의 EN/KO 버튼으로 언어를 바꿀 수 있습니다.

저장 데이터
  원정 기록과 언어 · 음소거 설정은 아래 폴더에 저장되며, 새 버전으로 폴더를 바꿔도 유지됩니다.
    %APPDATA%\games.contourbound.cartorogue
  완전히 삭제하려면 게임 폴더와 위 폴더를 지우면 됩니다.

[English]

How to run
  1. Right-click the zip file and choose "Extract All". Do not run the game from inside the zip.
  2. Open the extracted folder and run CartoRogue.exe.
     Nothing is installed, and the whole game plays without an internet connection.

  If "Windows protected your PC" appears
     This build is not code-signed, so SmartScreen may warn about a downloaded file.
     Click "More info", then "Run anyway".

  Requirements: Windows 10 or Windows 11 (64-bit)

Controls
  Arrow keys / WASD  Move (click the map to step toward that spot; hold to keep walking)
  Enter / Space      Start / confirm
  R                  New map
  P / Esc            Pause menu
  L                  Expedition Archives (title and result screens)
  H                  Hide / show the result card
  M                  Mute
  F                  Toggle fullscreen
  The EN/KO button at the bottom right switches the language.

Saved data
  Records and the language / mute settings are kept in the folder below and survive replacing the
  game folder with a newer build:
    %APPDATA%\games.contourbound.cartorogue
  To remove everything, delete the game folder and that folder.
